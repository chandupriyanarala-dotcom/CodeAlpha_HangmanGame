# CodeAlpha_HangmanGame

## Description
A simple text-based Hangman game developed using Python as part of the CodeAlpha Python Programming Internship.

## Features
- Randomly selects a word from a predefined list
- Allows the player to guess one letter at a time
- Allows up to 6 wrong guesses
- Shows correct and incorrect guesses
- Displays a winning or game-over message

## Technologies Used
- Python
- Random module
- Loops
- Conditional statements
- Lists
- Strings

## How to Run
1. Install Python.
2. 2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run:

python hangman_game.py
